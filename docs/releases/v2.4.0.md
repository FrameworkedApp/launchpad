# LaunchPad v2.4.0

## The marketplace is now `frameworked`

LaunchPad's marketplace is renamed from `builtform` to `frameworked`, so new installs use `launchpad@frameworked`. The marketplace repository is the same (`FrameworkedApp/marketplace`), and existing installs keep working.

## Changed

- **New install id: `launchpad@frameworked`.** The README, How It Works, the contributing guide, the issue templates and the release process use the new name. On Claude Code the cache of a new install is `~/.claude/plugins/cache/frameworked/launchpad/<version>/`.
- **License holder is Frameworked LLC.** The MIT license is unchanged; only the copyright holder changes.

## Internal

- The install-layout tests run against both marketplace cache names, `builtform` and `frameworked`, since both stay in use.

## Upgrading from v2.3.x

Nothing breaks. Choose by host:

- **Claude Code:** a `launchpad@builtform` install keeps working and keeps receiving releases. To move to the new name, run `/plugin marketplace remove builtform` (this also uninstalls the marketplace's plugins), `/plugin marketplace add github:FrameworkedApp/marketplace`, then `/plugin install launchpad@frameworked`. Projects that pin LaunchPad in `.claude/settings.json` rename the `extraKnownMarketplaces` key and the `enabledPlugins` entry from `builtform` to `frameworked`.
- **Codex:** a `launchpad@builtform` install keeps working but receives no further releases, because `codex plugin marketplace upgrade builtform` now reports a name mismatch. Move to the new name, removing the plugin before the marketplace:

  ```bash
  codex plugin remove launchpad@builtform
  codex plugin marketplace remove builtform
  codex plugin marketplace add FrameworkedApp/marketplace
  codex plugin add launchpad@frameworked
  ```

Start a new session after moving. Details are in [How It Works: Updating](../guides/HOW_IT_WORKS.md#updating) and [Updating and removing on Codex](../guides/HOW_IT_WORKS.md#updating-and-removing-on-codex).

## Release validation

- Python suite (2500 passed, 5 skipped), TypeScript tests, typecheck, lint, Pyright, Ruff, the handshake lint including the schema gate, and the release freshness gate pass on the release branch.
- The plugin ships 43 commands, 16 skills and 39 agents, unchanged from v2.3.1, and the Codex router's command inventory lists all 43.
- Both hosts were tested against a renamed marketplace (Claude Code 2.1.258, Codex 0.167.0-alpha): existing `launchpad@builtform` installs keep working, and both accept the catalog without an owner email.
- The live Codex install check in the maintainer release process was not run for this release.
